# Polymer Monthly art

Image assets for the *Polymer Monthly* newsletter emails. These are procedural micrograph-style textures: polymer spherulites under crossed polarizers, birefringent crystal shards, H&E-style tissue and confocal-style fluorescence. They are generated from scratch, not taken from any publication.

- `masthead-titled-*.jpg` mastheads with the title drawn in (rotate by issue)
- `masthead-*.jpg` untitled masthead backgrounds
- `strip-*.jpg` chapter-opener and footer bands
- `edge-*.jpg` top edges of the paper plates
